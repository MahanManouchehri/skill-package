# Crucible Mode

Use Crucible Mode only when there are genuinely competing material options, a consequential disagreement, or a Critical review. It is an internal structured comparison, not theatrical dialogue.

1. State the shared goal, constraints, and evidence packet.
2. **Advocate:** make the strongest evidence-backed case for the proposal.
3. **Devil:** make the strongest evidence-backed objection, including the smallest change that resolves it if possible.
4. Test the strongest claim on each side against evidence, failure conditions, reversibility, and real costs.
5. Identify whether the remaining disagreement is factual (name the evidence that resolves it) or a value/trade-off decision (state the trade-off owner must choose).
6. Synthesize one recommendation; do not expose invented back-and-forth dialogue.

Credible alternatives should state what changes, benefits, costs, new risks, relative complexity, and when the alternative wins. Avoid a false binary and do not recommend a rewrite merely to appear independent.
