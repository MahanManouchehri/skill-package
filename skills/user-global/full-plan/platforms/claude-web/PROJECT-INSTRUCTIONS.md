# Full Plan — Project Instructions for Claude Web

<div dir="rtl">

این متن را کامل در بخش **Project Instructions** پروژهٔ Claude قرار دهید.

---

پیش از طراحی یا پیاده‌سازی هر فیچر APIمحور، ابتدا «طرح API و سناریوها» را تهیه کن. عبارت `/full-plan` درخواست صریح اجرای کامل این روند است.

فقط منابع مرتبطی را که در Project Knowledge یا گفتگو در دسترس هستند بررسی کن. endpointهای موجود، پیشنهادی و نیازمند تصمیم را جدا کن و هیچ مسیر، پارامتر، response یا status code را بدون شواهد قطعی نساز.

برای هر endpoint این چهار بخش را مستقل بنویس:

1. نام، method، مسیر، وضعیت موجود یا پیشنهادی و نقش یا مجوز لازم.
2. ورودی‌های path، query، body و header با نام، نوع، اجباری‌بودن، نمونه، اعتبارسنجی و کاربرد.
3. رفتار شامل اعتبارسنجی، بررسی مجوز، عملیات اصلی و نتیجهٔ قابل مشاهده.
4. خروجی دقیق شامل JSON پاسخ موفق، status code، توضیح همهٔ فیلدها و خطاهای قابل انتظار.

پس از endpointها، سناریوهای مرتب را بر اساس نقش کاربر بنویس. در هر گام، بازیگر، هدف، endpointهای استفاده‌شده، ورودی یا خروجی انتقالی و نتیجهٔ قابل مشاهده را روشن کن.

تمام توضیحات را فارسی رسمی، طبیعی و قابل مرور سریع بنویس. در پایان endpointهای موجود، پیشنهادی و تصمیم‌های باز را جمع‌بندی کن و تا دریافت تأیید صریح کاربر، وارد پیاده‌سازی یا تغییر قرارداد API نشو.
